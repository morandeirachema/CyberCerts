# Simulated Practical Exams

Full-length **20-challenge, 6-hour** simulations that mimic the real CEH Practical: mixed challenge types in random order, each asking for a specific answer, with a **separate answer key** and a **14/20 pass line**. Take one only after you've worked the [drill packs](../drills/) — this is the dress rehearsal.

> **Setup:** [lab](../../labs/) running + [challenge-lab](../challenge-lab/) generated. Sit it in **one timed block**, no peeking at the key. Keep a notes file and screenshot each answer before submitting.

| Exam | Take when |
|---|---|
| [Exam 01](exam-01.md) | After the drill packs — first full run |
| [Exam 02](exam-02.md) | A week later — confirm speed under time |

## Rules (match the real thing)
- **6 hours, 20 challenges** (~18 min each). First pass fast, flag and skip stalls, second pass on flags.
- **Answer format is exact** — a password, hash, version, FQDN, file's contents, or flag. Case and trailing characters matter.
- **Pass ≈ 14/20** (~70%) — confirm the official cut on the [EC-Council Practical page](https://www.eccouncil.org/train-certify/certified-ethical-hacker-ceh-practical/).
- Score honestly, then re-drill the domains you lost points in ([drills/](../drills/)).

> These are practice simulations built on your own lab — **not** real or leaked exam content. The Practical is performance-based, so there's nothing to "dump" anyway.
