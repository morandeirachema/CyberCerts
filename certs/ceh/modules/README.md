# CEH v13 Modules

One guide per official module. Each follows the same structure ([`00-TEMPLATE.md`](00-TEMPLATE.md)):

1. **Exam focus** — what CEH actually tests here
2. **Key concepts** — the testable facts, taxonomies, definitions
3. **Key tools** — with official links
4. **Commands & techniques** — real, lab-ready syntax
5. **Lab exercise** — run it against *your* [`../labs/`](../labs/) targets
6. **Defender & PAM mapping** — tie each attack to the control you manage
7. **Exam tips & gotchas**
8. **Sources** — official / well-known references only
