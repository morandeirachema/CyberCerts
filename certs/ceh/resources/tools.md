# CEH Toolset (by phase)

The tools CEH expects you to recognize, grouped by where they're used. Homepages only — install most of these from Kali (`sudo apt install <tool>`) or their repos. Kali tool docs: https://www.kali.org/tools/

## Recon / footprinting (Module 02)
- theHarvester — https://github.com/laramies/theHarvester
- Recon-ng — https://github.com/lanmaster53/recon-ng
- Maltego — https://www.maltego.com/
- Shodan — https://www.shodan.io/  ·  Censys — https://censys.io/
- HTTrack (site mirroring) — https://www.httrack.com/
- dnsrecon — https://github.com/darkoperator/dnsrecon  ·  dnsenum, dig, whois (Kali built-ins)

- Masscan — https://github.com/robertdavidgraham/masscan
- hping3 — https://github.com/antirez/hping
- Angry IP Scanner — https://angryip.org/
