# Certifications

All the certification study hubs live here, each a self-contained folder built to the same
standards (Mermaid diagrams, source-grounded, no fabrication, a `Sources` section per page).
Shared fundamentals they all draw on — [foundations/](../foundations/README.md),
[prerequisites/](../prerequisites/README.md), [protocols/](../protocols/README.md),
[reference/](../reference/README.md), [learning/](../learning/README.md) — stay at the repo root.

The order below is the suggested path for a sysadmin heading to a PAM architect role —
**CEH first**; see the [roadmap](../learning/roadmap.md) for the reasoning and the
professional skill ladder behind it.

| Phase | Hub | What it is | Depth |
|-------|-----|-----------|-------|
| **1 · now** | 🎯 **[ceh/](ceh/README.md)** | EC-Council Certified Ethical Hacker v13 + CEH Practical | **Full course**: concept pages, 20 modules × (guide · facts · questions · flashcards · lab), Kali course, runnable lab, mock exams, defender/PAM knowledge base, OT security |
| 2 | 🔵 [cysa-plus/](cysa-plus/README.md) | CompTIA CySA+ (CS0-003) — blue team / SOC, detection & response | 4 domains, exam prep, glossary |
| 2 *(optional)* | 🧱 [security-plus/](security-plus/README.md) | CompTIA Security+ (SY0-701) — vendor-neutral baseline | 5 domains, exam prep, cheat sheet, acronyms, glossary |
| 3 | 🟠 [pentest-plus/](pentest-plus/README.md) | CompTIA PenTest+ (PT0-003) — vendor-neutral pentesting + reporting | 5 domains, exam prep, cheat sheet, glossary |
| 3 | 🟣 [pnpt/](pnpt/README.md) | TCM Security PNPT — practical engagement + live debrief | 5 engagement phases, study plan |
| 3 | 🔴 [oscp/](oscp/README.md) | OffSec OSCP / OSCP+ (PEN-200) — hands-on offensive (24-hour exam) | 6 skill areas, exam structure, study plan |
| 4 | 🧩 [adjacent-certs/](adjacent-certs/README.md) | One-page overviews: CISSP, cloud security (AZ-500 / AWS), plus short orientations for Security+, OSCP, PNPT | Orientation pages |

> **Out of scope by design:** vendor PAM certifications (WALLIX, CyberArk, Palo Alto
> Networks…). PAM is taught vendor-neutrally in [foundations/](../foundations/README.md) and
> the CEH hub's [defender-pam/](ceh/defender-pam/README.md) knowledge base.

See the [root README](../README.md) for the whole-repo map, the
[learning roadmap](../learning/roadmap.md) for how these fit a career path, and the
[attack → defense matrix](../attack-to-defense-matrix.md) for how offensive techniques map to
the defensive (PAM) controls that stop them.
